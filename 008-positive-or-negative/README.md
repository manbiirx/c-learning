# 008 - Positive, Negative, or Zero Number Checker

This program demonstrates the use of `if`, `else if`, and comparison operators to determine whether a user-entered integer is positive, negative, or zero.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- `if`
- `else if`
- Comparison operators (`==`, `>`, `<`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will check if your number is positive or negative.
Enter your number: 15
The number is positive
```

### Other Examples

```text
This program will check if your number is positive or negative.
Enter your number: -8
The number is negative
```

```text
This program will check if your number is positive or negative.
Enter your number: 0
```
