# 011 - OTP Validation Using `if-else`

This program demonstrates the use of the `if-else` statement to validate a One-Time Password (OTP). It compares the user-entered OTP with a predefined value (`2503`) and displays whether the OTP is valid or invalid.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- `if`
- `else`
- Comparison operator (`==`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will check the validity of your OTP.
Enter your OTP: 2503
The OTP is valid
```
