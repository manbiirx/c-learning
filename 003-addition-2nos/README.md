# 003 - Addition of Two Numbers

This program takes two integer inputs from the user and displays their sum.

## Concepts

#include <stdio.h>
main()
printf()
scanf()
Variables
Arithmetic operator (+)

## Run

gcc main.c -o main
./main

## Output

Enter the value of a:
5
Enter the value of b:
7
The sum of a and b is: 12
