# 002 - User Input

This program asks the user to enter their name and then displays a personalized greeting.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Character arrays (`char[]`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will display the name of the user after the user inputs their name.
John
Hello, John
```
