# 014 - Percentage and Grade Calculator

This program demonstrates how to calculate the percentage of marks obtained in five subjects and determine the corresponding grade using `if-else if` statements.

The program calculates the average of the five entered marks and assigns a grade based on the calculated percentage.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- Integer and floating-point data types (`float`)
- Arithmetic operators (`+`, `/`)
- `if`
- `else if`
- `else`
- Comparison operators (`>=`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will calculate your percentage.
Enter your marks: 85 92 78 88 95
Your percentage is: 87.599998
Grade B
```
