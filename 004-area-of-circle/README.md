# 004 - Area of a Circle

This program calculates the area of a circle by taking the radius as input from the user and displaying the calculated area.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- Integer and Double data types
- Arithmetic operators (`*`)
- Formula for the area of a circle (`πr²`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will find area of the circle.
Enter radius r:
5
Area =78
```
