# 009 - Odd or Even Number Checker

This program demonstrates the use of the modulus (`%`) operator and the `if-else` statement to determine whether a user-entered integer is odd or even.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- `if`
- `else`
- Modulus operator (`%`)
- Comparison operator (`==`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will determine if your number is odd or even.
Enter your number: 24
The number is even
```

### Other Example

```text
This program will determine if your number is odd or even.
```
