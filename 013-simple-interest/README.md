# 013 - Simple Interest Calculator

This program demonstrates how to calculate **Simple Interest (SI)** using the formula:

**Simple Interest = (Principal × Rate × Time) / 100**

The program accepts the principal amount, rate of interest, and time period from the user, calculates the simple interest, and displays the result.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- Integer and floating-point data types (`int`, `float`)
- Arithmetic operators (`*`, `/`)
- Simple Interest formula

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will find Simple Interest
Enter Principal Amount: 10000
Enter the Rate of Interest: 5
Enter the Time in years: 2
```
