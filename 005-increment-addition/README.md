# 005 - Increment Operator

This program demonstrates the use of the increment (`++`) operator by taking an integer input from the user, increasing its value by one, and displaying the result.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- Increment operator (`++`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will perform increment operator (additive) on the number entered by the user
Enter your number
10
addition by ++ = 11
```
