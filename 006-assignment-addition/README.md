# 006 - Assignment Operator (`+=`)

This program demonstrates the use of the addition assignment (`+=`) operator by taking an integer input from the user, adding `100` to it, and displaying the result.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- Assignment operator (`+=`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
This program will add 100 to your number by using assignment operator.
Enter your number.
25
Answer :125
```
