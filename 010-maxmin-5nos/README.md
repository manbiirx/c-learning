# 010 - Find the Maximum and Minimum of Five Numbers

This program demonstrates the use of `if`, `else if`, and the logical AND (`&&`) operator to determine the largest and smallest values among five user-entered integers.

## Concepts

- `#include <stdio.h>`
- `main()`
- `printf()`
- `scanf()`
- Variables
- `if`
- `else if`
- Logical AND operator (`&&`)
- Comparison operators (`>=`, `<=`)

## Run

```bash
gcc main.c -o main
./main
```

## Output

```text
Enter 5 numbers: 12 45 8 30 19
Maximum = 45
Minimum = 8
```

### Another Example

```text
Enter 5 numbers: -4 -10 7 0 3
Maximum = 7
Minimum = -10
```
